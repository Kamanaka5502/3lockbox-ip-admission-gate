# 3LOCKBOX Holographic Console V2 — Implementation Specification

## Objective

Turn the live admission demo into an immersive governance instrument while keeping every state-changing visual bound to real API behavior.

## Visual stack

1. **Deep field** — particles, scan lines, coordinate lattice.
2. **Global extremity field** — stylized world wireframe, latitude/longitude grid, scan sweep, interactive extremity nodes.
3. **Symbolic execution field** — orbiting formulas, hashes, thresholds, calculus/tensor glyphs.
4. **3D consequence reactor** — multi-shell transparent sphere, nested rotating rings, refractive shell, inner core, decision color field.
5. **Boundary intelligence layer** — hover/focus nodes reveal purpose, evidence, consequence authority, failure closure, and architectural blind spot addressed.
6. **Proof layer** — deterministic receipt hash, tamper-evident ledger hash, replay and chain verification.

## Runtime binding rules

- `PENDING` accelerates the world scan, math field, and reactor rings.
- `ADMIT` resolves to green/cyan.
- `REVIEW` resolves to amber/gold.
- `REFUSE` resolves to red/crimson.
- Stage activation follows the real pipeline: `candidate -> evidence -> policy -> consequence -> proof`.
- The displayed receipt hash must mirror the real `/api/v1/admit` response.
- Ledger status and event stream must come from `/api/v1/ledger` and `/api/v1/ledger/verify`.
- Symbolic numeric motion is explicitly labeled as visualization telemetry, not a backend metric.

## Interaction model

- Pointer movement tilts the 3D field with differential parallax: world plane moves least, math field more, reactor most.
- Hover/focus on a boundary node lights all matching map nodes and relevant math formulas.
- Hover cards remain keyboard accessible and include a close control.
- Reduced-motion users retain a static but complete visualization.

## Boundary set

- Candidate Surface
- Evidence Acquisition Boundary
- Policy Admission Boundary
- Consequence Lock Boundary
- Proof Emission Boundary
- Ledger Continuity Boundary
- Authority Custody Boundary
- Replay Integrity Boundary
- Admissibility Threshold

## Core reactor behavior

### Idle
- slow shell counter-rotation
- inner core pulse
- low-intensity world sweep
- formulas orbit at independent radii and depths

### Evaluation
- reactor moves forward in Z depth
- rings accelerate
- map nodes sequence on
- formulas associated with the active pipeline stage brighten

### Decision
- decision color floods the state field
- proof layer stabilizes
- map intensity decays after a brief lock pulse

## Success condition

A first-time judge should understand within seconds that 3LOCKBOX is not a lookup dashboard. It is an evidence-to-authority-to-consequence-to-proof system with explicit failure closure and replayable custody.
